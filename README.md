# gametest2

Fast-dev demo: Axis & Allies 1942 (2nd Edition) board map, no units. 96 land territories (incl. 16 impassable neutrals) + 65 sea zones.
Territory list, owners and IPCs from TripleA's `world_war_ii_v5_1942` map (https://github.com/triplea-maps/world_war_ii_v5_1942).
Play: https://nasoteisoy.github.io/gametest2/
